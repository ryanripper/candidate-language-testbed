# Data Science Skills and Methods Notes:

## 07/20/26 - Topic Modeling in Research

- Discover hidden themes in text data
- Option to use for focus group/qualitative data analysis
- Option to use this approach as a way to avoid subject coding of certain statements/themes/indicators

1. Latent Dirichlet Allocation (LDA)
- Each document is a mixture of several topics and each topic is a mixture of words
- Aims to find the distribution of topics in each document and distribution of words in each topic
- Simple and effective

2. Non-Negative Matrix Factorization (NMF)
- Decomposes the document-term matrix into 2-lower dimensional matrices
- One of these matrices represents topics
- Another represents document-topic associations

3. Latent Semantic Analysis (LSA)
- Uses singular value decomposition to reduce the dimensions of the document-term matrix
- Uncovers the latent structure of the text data

- Like the idea of identifying "latent" topics in the text data
- Fear with topic modeling that it finds themes that are too:
-- Broad
-- Inclusive
-- Difficult to interpret
-Where does topic modeling and other NLP approaches now sit with AI?
-- Can the two exist together?
-- Does topic modeling become obsolete?
-- Is AI good enough to identify themes? Identify trends? Identify groups?
